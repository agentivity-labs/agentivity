# Images

Pictures used by the README. They come from the real Studio and the real example apps, recorded on fictitious data.
The animated pictures are GIFs made from the clips of agentivity.io (GitHub plays a GIF everywhere; a video file does not
play from a relative path). Keep each one under about 2 MB.

| File | Used for |
|---|---|
| `studio-hero.png` | Top of the README: the Studio with a team on the canvas |
| `studio-team.gif` | "Build a team in your browser": naming a team, choosing how it works, dragging in specialists |
| `studio-workflow.gif` | The same section: drawing a workflow |
| `showcase-trip.gif` | "Turn it into a VibeApp": the Trip Planner app |
| `showcase-cv.gif` | "See real examples": the CV Screening workflow |

To remake a GIF from a clip: 10 images per second, 720 to 800 px wide, a 96-colour palette (`ffmpeg`, `palettegen` then
`paletteuse`).
